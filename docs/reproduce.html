Check the work

The repository holds the code and the full results. This page says how to rerun them.

pip install -r requirements.txt
python src/preprocess.py              # single substitutions with a numeric ddG_ML
python src/split_data.py              # grouped train / validation / test split
python src/train_models.py            # first baselines (F1)
python src/add_sequence_features.py   # neighbouring residues (F2)
python src/update_splits.py           # same split for the F2 files
python src/compare_models.py          # F1 vs F2 comparison
python src/evaluate.py                # everything on this site
python -m http.server -d docs         # open http://localhost:8000
Data
Download Processed_K50_dG_datasets.zip from Zenodo record 7401275 and unzip K50_dG_Dataset1_Dataset2.csv where src/preprocess.py expects it (see README). It is not committed: GitHub rejects files over 100 MB.
Split
. Cluster membership of every row is in the split files.
