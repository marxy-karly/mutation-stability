Run it yourself

Use a different dataset

Any CSV with a sequence column, a mutation column (single substitutions such as W34D), a numeric target and a group column. The file stays in your browser. Up to 6,000 rows are used.

Things to try: reshuffle a few times and watch how much the grouped scores move. That spread is why the results come with intervals.
